# Makro-Generator WoW Forever

Baut WoW-Forever-Makros für den deutschen oder englischen Client (Zaubernamen müssen in der Sprache des Clients stehen), prüft das 255-Zeichen-Limit und kopiert sie per Klick. Dazu eine Beispiel-Bibliothek je Klasse und die Makro-Grundlagen auf Deutsch.

Live: https://xerilolz.github.io/makro-generator/
